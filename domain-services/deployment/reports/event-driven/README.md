# Event-driven measurements (feature 005)

Load-client evidence for [feature 005](../../../../specs/005-event-driven-services/spec.md):
the event-driven build compared with the 004 build re-measured on the same host and profiles.

| Folder / file | Contents |
|---|---|
| `baseline-004/default/`, `baseline-004/stress/` | The 004 build at tag `pre-event-driven` (commit `601ba53079b534ace3655c3ea0fd2253913ddf59`), measured with the `default` and `stress100` profiles |
| `default/` | The event-driven build, `default` profile: the unchanged client with no workload flags (`java -cp out Main`, 10 stations × 60 s) |
| `stress/` | The event-driven build, `stress100` profile: `java -cp out Main --stations=100 --duration=120` |
| `NOTES.md` | The graded report for each profile, the topology and settings, error explanations, and p95 deltas against `baseline-004` |
| `COMPARISON.md` | Per-run rows and medians, generated by `../../scripts/compare-reports.sh` |

Each run writes three files that pair by the load client's timestamp: `report-<ts>.json`
(load client), `observations-<ts>.json` (`capture-observations.sh`), and
`reconciliation-<ts>.txt` (`reconcile.sh`). Runs are produced by
`../../scripts/run-measurement.sh` (research R11).
